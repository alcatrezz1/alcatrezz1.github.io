IK for tentacle legs. A tentacle needs an organic curve over many segments, so FABRIK instead of two-bone IK.

-- points is mutated in place. lengths holds (#points - 1) segment lengths.
function Fabrik.solve(points, lengths, origin: Vector3, target: Vector3, iterations: number, tolerance: number)
	local n = #points
	if n < 2 then
		return points
	end

	local total = 0
	for _, length in ipairs(lengths) do
		total += length
	end

	local toTarget = target - origin

	-- out of reach: the chain just stretches straight at the target
	if toTarget.Magnitude > total then
		local dir = safeUnit(toTarget, Vector3.new(0, -1, 0))
		points[1] = origin
		for i = 2, n do
			points[i] = points[i - 1] + dir * lengths[i - 1]
		end
		return points
	end

	for _ = 1, iterations do
		-- backward pass: pin the tip to the target, walk back to the base
		points[n] = target
		for i = n - 1, 1, -1 do
			local dir = safeUnit(points[i] - points[i + 1], Vector3.new(0, 1, 0))
			points[i] = points[i + 1] + dir * lengths[i]
		end
		-- forward pass: pin the base back to the shoulder, walk out to the tip
		points[1] = origin
		for i = 2, n do
			local dir = safeUnit(points[i] - points[i - 1], Vector3.new(0, -1, 0))
			points[i] = points[i - 1] + dir * lengths[i - 1]
		end
		if (points[n] - target).Magnitude <= tolerance then
			break
		end
	end

	return points
end

Every remote is declared once with its own budget. Spam is dropped before any handler runs, and handlers still validate every argument.

type Bucket = { Tokens: number, Stamp: number }
local buckets: { [Player]: { [string]: Bucket } } = {}

-- server side listener with the rate limit already applied
function Network.onServer(name: string, handler: (Player, ...any) -> ())
	assert(IS_SERVER, "onServer is server only")
	local definition = Network.Definitions[name]
	assert(definition, "undeclared remote " .. name)

	Network.get(name).OnServerEvent:Connect(function(player: Player, ...: any)
		local perPlayer = buckets[player]
		if not perPlayer then
			perPlayer = {}
			buckets[player] = perPlayer
		end
		local now = os.clock()
		local bucket = perPlayer[name]
		if not bucket then
			bucket = { Tokens = definition.Burst, Stamp = now }
			perPlayer[name] = bucket
		end
		bucket.Tokens = math.min(definition.Burst, bucket.Tokens + (now - bucket.Stamp) * definition.Rate)
		bucket.Stamp = now
		if bucket.Tokens < 1 then
			return
		end
		bucket.Tokens -= 1
		handler(player, ...)
	end)
end

Game design

Rules first, then feel

I write the rules down before I touch Studio. Three that run through everything I designed for GRAFT:

Skill over stats

Levels unlock features, not damage. No auto-aim. A new player with good aim can beat a veteran.

Costs you can see

Skills spend real tentacles. Throw your arm as a spear and you fight with one arm less until it grows back.

Never pay to win

Monetization is skins only. Everyone shares one body, so a skin is visible and progress stays earned.

The core loop I designed
R1

Tentacles are health

100 HP each, 34 per hit. The last one torn is death.

R2

Legs or arms

Legs give height, speed and reach. Arms do the hitting.

R3

A kill grows you

+1 tentacle per kill. Dying in a fight halves what you own.

R4

Combat locks healing

12 seconds after a hit. Then one tentacle regrows every 4 seconds.

Playtest decisions

What testers showed me, and what I changed

Skills with no punch

Problem

Two skills worked but felt like nothing happened.

Change

Replaced them with SLAM, which hits legs, and SPEAR, where you throw your own arm.

Result

Skills cost a body part. That reads instantly.

A boss you could kite

Problem

On 5 legs you could circle the first keeper forever.

Change

Lead aim, a sweep you can't sidestep, rage on long misses, no self-heal.

Result

Testers called it long, hard and fun.

Three hits was too flat

Problem

Every limb broke in 3 hits, so tougher zones had nowhere to go.

Change

HP per tentacle. Levels give no HP and no damage.

Result

Room for poison, mutations and new zones.

Bunny hopping

Problem

Chained jumps beat walking on many legs.

Change

A running jump ends in a heavy landing.

Result

Leg count decides speed again.
